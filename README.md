# cilsocarvalho.github.io

Portfolio of **Cilso Carvalho**, Senior Cloud & DevOps Engineer — live at **https://cilsocarvalho.github.io**.

AWS architecture case studies from real work: containers on Amazon ECS and EKS, hybrid networking with Site-to-Site VPN, BGP and Direct Connect, multi-account FinOps, and AI-assisted operations on Amazon Bedrock. Each case shows the architecture, the problem, what was built, how it works and the key decisions. Internal names, account IDs and IPs are removed.

## Architecture diagrams as code

The diagrams in `public/architecture/` are generated by a small Python tool in `tools/diagrams/` that follows AWS Architecture Icons conventions — AWS Cloud, account, Region, VPC, subnet and Availability Zone groups, official service icons and numbered flows.

```bash
python3 tools/diagrams/diagrams.py            # regenerate every diagram
python3 tools/diagrams/diagrams.py aiops      # regenerate one
```

Case study text lives in `src/data/case-studies.ts`.

## Stack

React, TypeScript, Vite and Tailwind CSS, deployed to GitHub Pages by GitHub Actions on every push to `main`.

```bash
npm ci
npm run dev      # local preview
npm run build    # production build in dist/
```
